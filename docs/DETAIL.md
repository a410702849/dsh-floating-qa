# 悬浮问答

把对话里的任意一条「问题 + 回答」钉到对话界面上，形成一个长期悬浮、可拖拽的速查小列表。适合在长会话里反复查阅同一个结论、配置或代码片段。

## 用法

> 首次安装后，请刷新桌面端页面或重启 DeepSeek Harness，让新的客户端插件生效。

1. 在任意一条已完成的助手回答下方，点击操作行里的图钉按钮。
2. 对话左上角会出现「悬浮问答」小面板：第一次出现时，顶边贴紧会话顶部菜单栏的下边线，左边贴紧左侧栏右边线。
3. 拖动面板标题栏可以移动位置；位置会记住。
4. 拖动面板左边框或右边框都可以调整宽度：默认宽度为 259px（原 324px 的 8/10），最小 130px，最大不超过当前桌面端窗口宽度；窗口变窄时会自动收缩到可见范围内。
5. 点击列表里的任意一条，会弹出遮罩层显示完整问答；回答里的 Markdown（标题、列表、代码块、表格、引用、链接等）会按 Markdown 样式渲染，和主对话里的显示方式一致。按 `Esc`、点击遮罩或「关闭」退出。
6. 点击条目右上角的 `×`，或打开全文后点「取消悬浮」，可以移除。
7. 点击面板右上角齿轮，可调整最多悬浮条数（默认 3 条）；同一设置行里的「取消所有悬浮」按钮只会清空**当前会话**的悬浮条目，不影响其他会话。设置面板的展开/收起状态也按会话分别记忆，切换会话时互不影响。

## 安装与更新

在 DSH 插件市场搜索 **dsh-floating-qa** 安装。

首次安装后，请刷新桌面端页面或重启 DeepSeek Harness。插件以普通 npm 包分发，更新时在市场安装新版本即可，不需要手动改 profile。

本地开发时，也可以通过 DSH 的 bundle 安装入口选择本目录；源码修改后刷新或重启即可。

## 行为细节

- 小列表默认高度约为三组问答；超过后在列表内部滚动。
- 顶部位置会随会话顶部菜单栏的实际高度变化（标签页换行、顶部栏高度变化时会自动下移），不会默认压住菜单栏。
- 问题行与回答行使用不同的背景色和字体色，便于快速区分。
- 问题、回答都只显示一行，超出部分显示省略号；完整内容在遮罩层查看。
- 悬浮状态按会话隔离，并保存在浏览器 `localStorage` 中，重启后仍在。
- 不同会话各自维护自己的悬浮列表；切换会话时只显示当前会话的条目。
- 最多条数默认 3，可在面板内调整（1–20 条）；调小时会保留最新的条目并移除超出部分。
- 数据只保存在本地，插件不会上传问答内容，也不会修改对话历史。

## 兼容性

- 需要 DeepSeek Harness 桌面端（Web 客户端）。
- 插件只注册两个客户端槽位：助手消息操作行 `conversation.chat.assistant-actions` 与根级浮层 `shell.overlay`，不修改对话数据。
